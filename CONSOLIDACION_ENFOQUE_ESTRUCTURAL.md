## 1. INDUSTRIAL: 5 → 3 especialidades

### Especialidades actuales (5):
1. Bodegas de Gran Escala
2. Plantas Farmacéuticas
3. Ingenios Azucareros
4. Cuartos Fríos Industriales
5. Hangares Aeronáuticos

### ✅ PROPUESTA CON ENFOQUE ESTRUCTURAL:

#### Opción 1:
1. **Naves Industriales de Gran Luz**
   - Incluye: Bodegas + Hangares
   - Enfoque: Estructuras de 1 nivel con grandes luces sin columnas (20-50m)
   - Proyectos: Tecnosur, hangares, bodegas

2. **Edificios Industriales de Múltiples Niveles**
   - Incluye: Farmacéuticas + Ingenios (edificios multi-piso con entrepisos técnicos)
   - Enfoque: Estructuras verticales con entrepisos metálicos para equipos y procesos
   - Proyectos: Tecnoquímicas, Providencia, plantas industriales

3. **Estructuras Especializadas de Alta Resistencia**
   - Incluye: Cuartos Fríos + Estructuras pesadas
   - Enfoque: Estructuras con requerimientos especiales (corrosión, vibración, cargas extremas)
   - Proyectos: Cuartos fríos, ingenios (parte estructural pesada)

#### Opción 2:
1. **Naves de Gran Escala sin Columnas**
   - Incluye: Bodegas + Hangares
   - Enfoque: Gran luz, 1 nivel, espacios abiertos

2. **Estructuras Industriales Multinivel**
   - Incluye: Farmacéuticas + Ingenios + Plantas
   - Enfoque: Varios pisos con entrepisos metálicos

3. **Estructuras para Ambientes Controlados**
   - Incluye: Cuartos Fríos + Estructuras anticorrosivas
   - Enfoque: Ambiente extremo (frío, humedad, corrosión)

## 2. PUENTES: 6 → 3 especialidades

### Especialidades actuales (6):
1. Puentes de Gran Luz (Vehiculares y Peatonales)
2. Puentes en Arco Metálicos
3. Puentes Peatonales y de Acceso
4. Puentes Colgantes (Vehiculares y Peatonales)
5. Diseño Sísmico de Puentes
6. Puentes Sociales para Comunidades Rurales

### ✅ PROPUESTA CON ENFOQUE ESTRUCTURAL:

#### Opción 1:
1. **Puentes de Vigas y Cerchas**
   - Incluye: Gran Luz + Arco (sistemas de vigas/cerchas)
   - Enfoque: Puentes con sistema estructural de vigas cajón o cerchas metálicas
   - Proyectos: Ovejas, Cascada, mayoría de puentes vehiculares

2. **Puentes Livianos Peatonales**
   - Incluye: Peatonales + Ciclopuentes
   - Enfoque: Estructuras ligeras para cargas peatonales, pasarelas
   - Proyectos: Ciclopuente Calle 98, pasarelas urbanas

3. **Puentes de Cables (Colgantes y Atirantados)**
   - Incluye: Colgantes + Puentes con cables
   - Enfoque: Sistema estructural mediante cables de acero
   - Proyectos: Puentes colgantes, puentes atirantados

#### Opción 2:
1. **Puentes Metálicos de Gran Luz**
   - Incluye: Gran Luz + Arco + Colgantes (todos los sistemas para luces grandes)
   - Enfoque: Luces superiores a 40m, diferentes sistemas estructurales

2. **Puentes Peatonales y Ciclísticos**
   - Incluye: Peatonales + Acceso ligero
   - Enfoque: Estructuras ligeras, cargas bajas

3. **Puentes Modulares Prefabricados**
   - Incluye: Sociales + Comunitarios (prefabricados, montaje rápido)
   - Enfoque: Sistema modular, fácil transporte e instalación

## 3. EDIFICACIONES: 6 → 3 especialidades

### Especialidades actuales (6):
1. Edificios Institucionales y de Oficinas
2. Parqueaderos Multinivel
3. Edificios Culturales Emblemáticos
4. Colegios y Estructuras Educativas
5. Edificios de Altura
6. Ampliaciones a Edificios Existentes

### ✅ PROPUESTA CON ENFOQUE ESTRUCTURAL:

#### Opción 1:
1. **Edificios de Estructura Metálica de Altura**
   - Incluye: Altura + Institucionales + Oficinas + Culturales
   - Enfoque: Edificios de 5+ pisos con pórticos metálicos o sistema mixto
   - Proyectos: Omega, Bomberos, Cinemateca, edificios corporativos

2. **Parqueaderos de Estructura Metálica**
   - Mantener separado (tipo específico de estructura)
   - Enfoque: Sistema de rampas y entrepisos para vehículos
   - Proyectos: Tequendama, CC Único

3. **Estructuras Metálicas Modulares y Ampliaciones**
   - Incluye: Colegios + Ampliaciones
   - Enfoque: Construcción modular rápida, ampliaciones sin interrumpir
   - Proyectos: Colegios modulares, ampliaciones Omega

#### Opción 2:
1. **Estructuras Verticales de Mediana y Gran Altura**
   - Incluye: Altura + Institucionales + Culturales
   - Enfoque: Sistema de pórticos metálicos, varios niveles

2. **Estructuras para Estacionamiento Multinivel**
   - Mantener: Parqueaderos
   - Enfoque: Sistema de entrepisos para vehículos

3. **Estructuras Modulares y Adiciones**
   - Incluye: Educativos + Ampliaciones
   - Enfoque: Montaje rápido, conexiones con estructura existente

## 4. DEPORTES: 5 → 3 especialidades

### Especialidades actuales (5):
1. Coliseos para Eventos Internacionales
2. Cubiertas de Grandes Luces sin Columnas
3. Torres Metálicas para Iluminación Deportiva
4. Piscinas Cubiertas y Complejos Acuáticos
5. Cubiertas Tensionadas y Membranas

### ✅ PROPUESTA CON ENFOQUE ESTRUCTURAL:

#### Opción 1:
1. **Cubiertas de Gran Luz para Escenarios Deportivos**
   - Incluye: Coliseos + Cubiertas Grandes Luces (cerchas espaciales, 40-75m luz)
   - Enfoque: Cerchas metálicas sin columnas internas, grandes espacios
   - Proyectos: Korfball, coliseos, canchas cubiertas

2. **Estructuras para Ambientes Especiales**
   - Incluye: Piscinas (alta humedad, corrosión)
   - Enfoque: Estructuras con tratamiento anticorrosivo especial
   - Proyectos: Piscinas Popayán, Pereira

3. **Estructuras Tensionadas y Torres Metálicas**
   - Incluye: Tensionadas + Torres
   - Enfoque: Mástiles, cables, membranas arquitectónicas, torres altas
   - Proyectos: Cubiertas tensionadas, torres de iluminación

#### Opción 2:
1. **Cerchas y Cubiertas Deportivas de Gran Luz**
   - Incluye: Coliseos + Cubiertas + Tensionadas
   - Enfoque: Todo tipo de cubiertas de gran luz

2. **Estructuras Metálicas para Natación**
   - Mantener: Piscinas
   - Enfoque: Ambiente de alta humedad

3. **Torres y Estructuras Auxiliares**
   - Incluye: Torres + Otros
   - Enfoque: Estructuras complementarias
